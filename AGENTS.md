# Правила для агентов (Claude Code и Codex)

1. Отвечать и писать документацию по-русски; команды, имена файлов и тексты ошибок — как есть.
2. Код решения — только вместе с тестами на `unittest`. Перед каждым коммитом запускать тесты своей папки: `python3 -m unittest discover -s <папка> -v`; коммитить только при зелёных тестах.
3. Без внешних зависимостей: только стандартная библиотека Python 3 (никаких `pip install`, `requirements.txt`).
4. Ключи, токены, пароли и личные данные в репозиторий не класть. В тестах — только вымышленные номера вида `918 123-45-67`.
5. Работать только в своей папке (`claude/` или `codex/`); чужие файлы не менять.
6. Сообщения коммитов — по-русски, с префиксом инструмента: `claude: …` или `codex: …`.
