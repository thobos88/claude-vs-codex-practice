# Задание: нормализация российских телефонных номеров

Этот текст без изменений получают оба агента (Claude Code и Codex). Соблюдать `AGENTS.md`.

## Что сделать

В папке своего инструмента (`claude/` или `codex/`) создать два файла:

- `phone.py` — функция `normalize_phone(value)`;
- `test_phone.py` — тесты на `unittest`.

## Правила

`normalize_phone(value)` возвращает строку вида `+7XXXXXXXXXX` (ровно 10 цифр после `+7`)
или `None`, если номер распознать нельзя. Исключения наружу не выбрасывать.

1. Вход — строка. Любой другой тип (`None`, число, список, `bytes`) → `None`.
2. Пробелы по краям строки игнорируются. Внутри номера допускаются только разделители:
   пробел, дефис `-`, скобки `(` и `)`. Любой другой символ (буква, точка, `/`, `#` и т. п.) → `None`.
3. Цифры — только ASCII `0`–`9`.
4. Знак `+` допускается не больше одного раза, только первым символом и только сразу перед `7`.
5. После удаления разделителей:
   - 11 цифр, первая `8` или `7` → `+7` и последние 10 цифр (если был `+`, первая цифра обязана быть `7`);
   - 10 цифр, первая `9` (мобильный без кода страны) → `+7` и эти 10 цифр;
   - всё остальное → `None`.

## Примеры

| Вход | Результат |
|---|---|
| `"8 (918) 123-45-67"` | `"+79181234567"` |
| `"+7 918 1234567"` | `"+79181234567"` |
| `"9181234567"` | `"+79181234567"` |
| `"7-918-123-45-67"` | `"+79181234567"` |
| `"  +7 (918) 123-45-67  "` | `"+79181234567"` |
| `""` | `None` |
| `"abc"` | `None` |
| `"12345"` | `None` |
| `"+8 918 123-45-67"` | `None` |
| `None` | `None` |

## Ограничения

- Только стандартная библиотека Python 3.
- Тесты покрывают все примеры выше и граничные случаи из правил 1–5.
- Запуск тестов: `python3 -m unittest discover -s <папка> -v` — все должны пройти.
- Один коммит, только файлы своей папки, сообщение по-русски с префиксом инструмента
  (`claude: …` или `codex: …`).
