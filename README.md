# Claude Code vs Codex — учебная практика

Учебный репозиторий курса по Claude Code (поток 18), практические задания 1 и 2.
Один небольшой кейс выполняют два агента — Claude Code и Codex — по одному и тому же
заданию и одним правилам, затем результаты сравниваются. Кейс нейтральный: рабочего кода,
данных, ключей и чужой интеллектуальной собственности здесь нет.

## Что внутри

- `AGENTS.md` — общие правила для агентов (Codex читает этот файл сам).
- `CLAUDE.md` — одна строка `@AGENTS.md`: Claude Code подключает те же правила импортом.
- `TASK.md` — текст задания, одинаковый для обоих агентов.
- `claude/` — решение Claude Code.
- `codex/` — решение Codex (запуск владельцем 29.09.2026, см. ниже).
- `compare.py` — прогоняет обе реализации на одном общем наборе входов.
- `COMPARISON.md` — сравнение результатов.

## Кейс

Функция `normalize_phone(value)` приводит российский номер телефона к виду `+7XXXXXXXXXX`
(«8 (918) 123-45-67» → `+79181234567`) или возвращает `None`, если номер распознать нельзя.
Точные правила — в [TASK.md](TASK.md). Все номера в тестах вымышленные.

## Как запустить проверки

Нужен только Python 3, внешних зависимостей нет. Из корня репозитория:

```sh
python3 -m unittest discover -s claude -v   # тесты решения Claude Code
python3 -m unittest discover -s codex -v    # тесты решения Codex
python3 compare.py                          # обе реализации на общем наборе входов
```

## Как владелец запускает Codex

Одна команда из корня репозитория (откроется интерактивный Codex, его шаги одобрять по ходу):

```sh
codex "$(cat TASK.md) Твоя папка — codex/: работай только в ней, папку claude/ не открывай. Перед коммитом запусти python3 -m unittest discover -s codex -v и закоммить только файлы codex/ одним коммитом с префиксом codex:."
```

После коммита Codex: запустить `python3 compare.py` и заполнить колонку Codex в
[COMPARISON.md](COMPARISON.md). Время прогона — от запуска команды до коммита
(`git log -1 --format=%cd`).
