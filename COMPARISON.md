Оговорки: TASK.md, набор кейсов `compare.py` и решение Claude написаны одним агентом (Claude), поэтому у него было знание задания; кейсы `compare.py` зафиксированы до написания решения; после этого в них заменён только один номер (495 → 118, чтобы все номера были заведомо вымышленными), правила ожиданий не менялись (тот же кейс «11 цифр с 8, не мобильный»). Claude работал как субагент, запущенный из другой рабочей папки: правила AGENTS.md он применил, прочитав файл, а не через автоматический импорт из CLAUDE.md.

Вывод: на простой задаче с чёткими правилами оба инструмента дали одинаково правильный результат (33 из 33 общих кейсов) и соблюли AGENTS.md — префикс коммита, только стандартная библиотека, только своя папка. Код почти одинаковый по объёму и подходу. Разница — в работе с человеком: Codex в интерактивном режиме спрашивает разрешение на команды (тесты, коммит) и требует доступную для аккаунта модель; Claude Code в этом прогоне работал как агент без подтверждений на каждом шаге. Правило в AGENTS.md одинаково сработало для обоих: Codex читает AGENTS.md сам, Claude Code — через `@AGENTS.md` в CLAUDE.md.
